# v1.0.0

## Entregas
- Fundação Axum/Tokio organizada em módulos.
- PostgreSQL via Docker e migrations SQLx.
- Cadastro, listagem, atualização e remoção de ativos.
- Regras de cálculo de valor investido, patrimônio, lucro/prejuízo e rentabilidade.
- Dashboard server-side com Askama.
- Identidade Futuristic Finance em preto, azul e dourado.
- Base de autenticação, movimentações e metas estruturada no banco.
- Validação de entradas e tratamento básico de erros.
- README com execução, tecnologias, melhorias, testes e aprendizados.
